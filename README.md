# Space Quiz

A lightweight, single-page quiz about space. It runs directly in a web browser and has no build step, server, or external dependencies.

## Run locally

Clone or download this repository, then open `index.html` in a web browser. Start the quiz, choose answers through all ten questions, and view your results.

## Deployment

The site is deployed to GitHub Pages from the `main` branch using the workflow in `.github/workflows/deploy-pages.yml`. The workflow publishes the repository as a static site without a build step.
